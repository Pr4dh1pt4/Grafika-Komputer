WebGL Fundamental — Primitive Playground

Deskripsi Praktikum

Membuat WebGL2 context, menyusun serta menghubungkan vertex & fragment shader, mengirim data posisi dan warna lewat buffer/attribute, lalu menggambar beberapa primitif dengan draw mode berbeda. Objek dianimasikan dan direspons terhadap mouse serta keyboard, persis seperti Praktikum 1 hanya seluruh proses rasterisasi kini dilakukan oleh GPU, bukan oleh Canvas 2D API.

02

Dari Shader ke Graphics Pipeline

Di Praktikum 1, Canvas 2D API menyembunyikan seluruh pipeline di balik satu pemanggilan seperti fillRect(). Di WebGL, tahapan itu ditulis eksplisit dan dijalankan oleh GPU secara paralel:

Vertex Buffer (posisi + warna)
→
Vertex Shader
→
Primitive Assembly
→
Rasterization
→
Fragment Shader
→
Framebuffer → Layar

Warna per-vertex yang terlihat halus/bergradasi pada mode Random bukan dihitung manual di JavaScript — itu adalah hasil interpolasi otomatis antar vertex yang dilakukan rasterizer GPU sebelum masuk ke fragment shader.
